# NIMEX Delivery Driver Performance (GitHub Pages)

เว็บ static + ฐานข้อมูลเป็น Google Sheet ผ่าน Apps Script. **ไม่มีข้อมูลจริงใน repo นี้**

## ติดตั้ง
1. สร้าง Google Sheet ใหม่ → Extensions > Apps Script → วางเนื้อหา `Code.gs.txt` (บันทึกเป็น Code.gs)
2. Project Settings > Script Properties → เพิ่ม `ADMIN_KEY` = รหัสผู้ดูแล (ตั้งเอง ยาวๆ)
3. Deploy > New deployment > Web app > Execute as: Me, Who has access: Anyone → คัดลอก URL `/exec`
4. แก้ `config.js` ใส่ `window.FLEET_API="URL ที่ได้"`
5. แก้ `og:image` ใน `index.html` (คำว่า YOUR-USERNAME/YOUR-REPO) ให้เป็นที่อยู่จริงของ cover.jpg
6. อัปโหลดทุกไฟล์ (รวมโฟลเดอร์ assets) ขึ้น GitHub → Settings > Pages > Deploy from branch
7. เปิด `https://<user>.github.io/<repo>/#admin` ใส่ ADMIN_KEY → ตั้งค่า > เติมไฟล์รายเดือน

## ใช้งานรายเดือน
ตั้งค่า > เติมไฟล์: ลากรายงาน NIMEX026001 + NIMEX06006 ของเดือนนั้น (อ่านในเบราว์เซอร์) → ตรวจผล → บันทึก
ถ้าเปลี่ยนข้อมูลแล้วผู้ชมยังเห็นของเก่า ให้เพิ่มเลข `FLEET_V` ใน config.js

## สิทธิ์การเห็น
- ผู้ชมทั่วไป: ผู้ดูแลกำหนดได้ที่ ตั้งค่า > เงื่อนไขและเกณฑ์ (ค่าเริ่มต้น หน้าหลัก + รายละเอียด DC) ถ้าเปิด รถบริษัท/เบี้ยขยัน ข้อมูลรายคนจะเปิดสาธารณะ
- ผู้ดูแล (`#admin` + key): รถบริษัท, เบี้ยขยัน, ตั้งค่า, ส่งออก
- repo/Pages เป็นสาธารณะ — ตัวเลขภาพรวมระดับบริษัท/DC ใครมี URL ก็เห็น

## เบี้ยขยัน
เงื่อนไขทั้งหมดแก้ได้ที่ ตั้งค่า > เงื่อนไขและเกณฑ์ (วันที่ต้องมา, สัปดาห์, เดือน) และ "วันยกเว้น" รายคนในรายชื่อพนักงาน

## อัปเดตล่าสุด
- KPI ใหม่ "อัตราการขึ้นขับ" (วันที่มีเที่ยว ÷ วันทำการ สูงสุด 100%) อยู่ตัวแรก รวม 5 KPI
- มาวันไหนก็ได้ · วันทำการ = จำนวนวัน − หยุดปกติสัปดาห์ละ 1 วัน (สัปดาห์ครบ 7 วัน) − จำนวนวันนักขัตของเดือน (กรอกที่ ตั้งค่า > เงื่อนไขและเกณฑ์) · นับถึงวันสุดท้ายที่มีข้อมูล
- ผลต่าง = เทียบกับวัน/สัปดาห์/เดือนก่อนหน้า ดี = เขียว แย่ = แดง
- แชร์ > สรุปรายบุคคล: PNG ทุกคน รวมเป็น ZIP

## อัปเดต (พ.ย. 2569)
- แท็บบนสุด = ทั้งหมด / รถบริษัท / รถผู้ประกอบการ กรองทุกหน้า (รถผู้ประกอบการซ่อนหน้ารถบริษัท ค่าจุดดรอป เบี้ยขยัน)
- ลาออก: ใส่ "วันสุดท้าย" ในรายชื่อ — ผลรายบุคคล/รายสัปดาห์/รายเดือนหยุดที่วันนั้น และไม่แสดงในรอบที่เริ่มหลังวันนั้น (เบี้ยขยันยังคำนวณตามรอบเดือน)
- กลุ่มการจ้างใหม่ "พนักงาน DC" (ไม่มีเบี้ยขยัน/ค่าจุดดรอป) · ตั้งค่า → รายชื่อพนักงาน มีรายการ "รายชื่อใหม่ในรายงาน" ให้ใส่รหัสและเลือกกลุ่ม
- หน้าบุคคลแสดง "ขึ้นขับล่าสุด" และเตือนเมื่อไม่มีเที่ยววิ่งเกิน 7 วันโดยยังไม่ใส่วันสิ้นสุด
- หน้า "ค่าจุดดรอป" (ค่าจัดส่งสำเร็จส่วนเพิ่ม, รถบริษัท): คิดรายวันจาก NIMEX06006 — จุด = ดรอปที่ส่งได้รวม (AY) + จำนวนดรอปเข้ารับ (AV), ประเภทงานของแต่ละใบงานดูจากคอลัมน์ F (ขึ้นต้น "เข้ารับ" = เข้ารับ, อื่นๆ = กระจาย) — จุดของใบงานกระจายคิดตามตารางกระจาย จุดของใบงานเข้ารับคิดตามตารางเข้ารับ แยกกันในวันเดียวกัน แล้วรวมค่าจุด · กระจาย: ขั้นต่ำ 35 จุด แล้ว 36–45 = 15, 46–55 = 20, 56–65 = 25, 66–75 = 30, 76+ = 35 บาท/จุด · เข้ารับ: ขั้นต่ำ 15 แล้ว 10 บาท/จุด · Outsource ANAR/MR +10 บาท/จุดทุกขั้น · ปรับอัตราได้ที่ ตั้งค่า → เงื่อนไขและเกณฑ์ · ต้องเติมไฟล์ NIMEX06006 ของเดือนนั้นใหม่หนึ่งครั้งเพื่อให้เก็บจุดดรอปรายวัน
- ส่งออก PNG รายบุคคล (ZIP) และราย DC (ปุ่มในแผ่น DC หรือ ZIP ทุก DC ในกล่องแชร์) จัดหน้าแบบรายงาน
